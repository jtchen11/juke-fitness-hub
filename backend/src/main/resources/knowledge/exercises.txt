# 常见动作扩充
## 高位下拉（Lat Pulldown）
标准姿势：
1. 坐在高位下拉机上，调整膝盖挡板固定大腿。
2. 双手宽握横杠，掌心向前，握距略宽于肩。
3. 肩胛骨下沉收紧，保持背部挺直。
4. 发力将横杠拉至上胸部，肘部贴近身体。
5. 控制节奏缓慢还原，感受背部拉伸。
常见错误：
1. 身体后仰过多 → 借力过多，减少背阔肌刺激。
2. 肘部外展 → 增加肩膀压力。
3. 耸肩 → 斜方肌代偿过多。
锻炼肌肉群：背阔肌、大圆肌、肱二头肌。

## 俯身划船（Bent Over Row）
标准姿势：
1. 双脚与肩同宽，膝盖微屈。
2. 俯身至躯干与地面约45度，保持背部挺直。
3. 双手正握杠铃或哑铃，握距与肩同宽。
4. 肘部贴近身体，将重量拉至下腹部。
5. 顶峰收缩1秒，缓慢还原。
常见错误：
1. 背部弯曲 → 容易损伤腰椎。
2. 身体晃动 → 借力过多。
3. 肘部外展 → 减少背部刺激。
锻炼肌肉群：背阔肌、斜方肌中下部、菱形肌、肱二头肌。

## 哑铃飞鸟（Dumbbell Fly）
标准姿势：
1. 仰卧在平凳上，双手持哑铃于胸部上方，掌心相对。
2. 肘部微屈，双臂向两侧打开至与肩同高。
3. 感受胸肌拉伸，发力还原至起始位置。
常见错误：
1. 肘部过度弯曲 → 变成卧推动作。
2. 手臂打开过低 → 增加肩关节压力。
锻炼肌肉群：胸大肌、三角肌前束。

## 哑铃侧平举（Dumbbell Lateral Raise）
标准姿势：
1. 站立，双手持哑铃于身体两侧，肘部微屈。
2. 肩部发力将哑铃向两侧举起至与肩同高。
3. 控制缓慢还原。
锻炼肌肉群：三角肌中束。

## 坐姿划船（Seated Cable Row）
标准姿势：
1. 坐在划船机前，双脚踩实踏板，膝盖微屈。
2. 双手握V形把手，背部挺直。
3. 肩胛骨发力将把手拉至上腹部。
4. 顶峰收缩，控制还原。
锻炼肌肉群：背阔肌、斜方肌中下部、菱形肌。

## 罗马尼亚硬拉（Romanian Deadlift）
标准姿势：
1. 站立，双手正握杠铃于大腿前侧，握距与肩同宽。
2. 保持背部挺直，膝盖微屈。
3. 髋部向后推，将杠铃沿大腿下滑至小腿中部。
4. 感受腘绳肌拉伸，发力站起还原。
锻炼肌肉群：腘绳肌、臀大肌、竖脊肌。

## 腿举（Leg Press）
标准姿势：
1. 坐在腿举机上，双脚与肩同宽踩在踏板上。
2. 解开安全锁，控制重量缓慢下放至膝盖呈90度。
3. 发力推起，不完全锁死膝盖。
锻炼肌肉群：股四头肌、臀大肌、腘绳肌。
