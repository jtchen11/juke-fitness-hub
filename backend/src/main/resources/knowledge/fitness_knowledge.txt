# 健身动作库

## 深蹲（Squat）
标准姿势：
1. 双脚与肩同宽，脚尖略微向外
2. 挺胸收腹，保持背部挺直
3. 臀部向后坐，膝盖与脚尖方向一致
4. 下蹲至大腿与地面平行
5. 发力站起，保持核心收紧

常见错误：
1. 膝盖内扣 → 容易损伤膝盖
2. 背部弯曲 → 容易损伤腰椎
3. 脚跟离地 → 稳定性差

锻炼肌肉群：股四头肌、臀大肌、核心肌群

## 杠铃卧推（Barbell Bench Press）
标准姿势：
1. 仰卧在卧推凳上，双脚踩实地面
2. 握距比肩稍宽，手腕保持中立
3. 杠铃下落至胸部上方
4. 发力推起，肘部微屈

呼吸方法：下落时吸气，推起时呼气

常见错误：
1. 手腕弯曲 → 容易损伤手腕
2. 肩胛骨未收紧 → 肩部压力大
3. 杠铃位置偏上/偏下 → 影响发力

锻炼肌肉群：胸大肌、三角肌前束、肱三头肌

## 硬拉（Deadlift）
标准姿势：
1. 双脚与髋同宽，杠铃在脚掌中间
2. 屈髋屈膝，保持背部挺直
3. 双手正握杠铃，肩胛骨收紧
4. 臀部发力站起，保持杠铃贴近身体

常见错误：
1. 背部弯曲 → 容易损伤腰椎
2. 臀部先抬起 → 下背部受力过大
3. 杠铃远离身体 → 力矩增大，容易受伤

锻炼肌肉群：竖脊肌、臀大肌、腘绳肌

## 卧推呼吸
杠铃卧推的正确呼吸方式：
1. 下落阶段（离心）：缓慢吸气，保持核心稳定
2. 底部停顿：屏息瞬间，保持身体张力
3. 推起阶段（向心）：用力呼气，同时发力推起
4. 顶部锁定：呼气完成，短暂调整

记住：下吸上呼，保持节奏，不要憋气过久。

# ====== 新增：减脂训练指南 ======

## 减脂核心原理
1. 减脂的核心是热量缺口（摄入 < 消耗）
2. 力量训练结合有氧是最高效的组合
3. 减脂期每周建议训练4-5次，每次60-90分钟
4. 有氧心率控制在最大心率的60%-70%（最大心率 ≈ 220 - 年龄）
5. 减脂期不要过度节食，保证蛋白质摄入

## 一周减脂训练模板（每周5练）
周一：胸+三头+30分钟有氧
周二：背+二头+30分钟有氧
周三：腿+肩+30分钟有氧
周四：胸+三头+30分钟有氧
周五：全身循环+30分钟有氧
周六：低强度有氧或瑜伽
周日：完全休息

## 减脂饮食原则
1. 高蛋白：维持肌肉量，增加饱腹感（每公斤体重1.6-2.2g）
2. 适量碳水：训练前补充能量，选择粗粮
3. 低脂肪：选择健康脂肪（坚果、鱼类、橄榄油）
4. 多吃蔬菜：补充维生素和膳食纤维
5. 每天喝2-3L水，避免含糖饮料
6. 每日热量控制在基础代谢的80%-90%

## 训练注意事项
1. 每次训练前热身10分钟，训练后拉伸10分钟
2. 力量训练重量选择：每组8-12次，做到力竭
3. 循序渐进，避免过度训练
4. 保证充足睡眠（7-8小时），促进恢复
5. 如感到不适，立即停止训练
